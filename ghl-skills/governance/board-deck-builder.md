# Board Deck Builder

Board decks that tell a story. Every section gets a headline, the data, the narrative, and a "so what."

Boards see ten decks a quarter. Yours needs a through-line, or the board will draw its own conclusions from your numbers — and theirs will be worse than yours.

## What you work from

You cannot pull metrics from any system. Ask the user for the numbers, by section. Where a number is missing, insert an explicit placeholder — `[ARR — NEEDED]` — and list every placeholder at the end so nothing ships blank.

**Never invent a metric.** A fabricated number in a board pack is the single worst failure available to this skill: it will be read by directors, minuted, and acted on.

## Deck structure

Every section runs: **headline → data → narrative → ask or next step.**

### 1. Executive summary — three sentences, no more

1. State of the business.
2. The biggest thing that happened this period.
3. Where you're going next quarter.

Weak: *"We had a good quarter with progress across all areas."*

Strong: *"We closed Q3 at $2.4M ARR, up 22% QoQ, signed our largest enterprise contract, and enter Q4 with 14 months of runway. The shift to mid-market is working — ACV up 40%, sales cycle down three weeks. Q4 priority is closing the Series A and hitting $2.8M."*

### 2. Key metrics — six to eight, in a table

| Metric | This period | Last period | Target | Status |
|---|---|---|---|---|
| ARR | | | | |
| MoM growth | | | | |
| Burn multiple | | | | |
| NRR | | | | |
| CAC payback | | | | |
| Headcount | | | | |

Use the metrics this board actually tracks. Drop anything they've said they don't care about — carrying a dead metric quarter after quarter trains them to skim.

Every metric needs a target and a status. A number with no target is trivia.

### 3. Financial update
P&L summary (revenue, COGS, gross margin, OpEx, net burn), cash position and runway, burn multiple across three quarters, variance to plan, forecast for next quarter.

**One sentence of cause on every variance.** "Revenue was below target" with no explanation reads as either not knowing or not saying, and boards assume the second.

### 4. Revenue and pipeline
ARR waterfall — starting, new, expansion, churn, ending. NRR and logo churn. Pipeline by stage in dollars, not deal count. Forecast with a confidence level. Top three deals with amount, close date and risk.

The forecast needs a confidence band. *"We expect $2.8M"* is weak. *"High confidence at $2.6M, upside to $2.9M if two late-stage deals close"* is something a board can plan against.

### 5. Product
Shipped this quarter, three to five bullets, each with user impact. Shipping next quarter with target dates. PMF signals — NPS trend, DAU/MAU, feature adoption. One key learning from customer research.

No feature lists. Only features with evidence of impact.

### 6. Growth and marketing
CAC by channel. Pipeline contribution by channel in dollars. Awareness metrics appropriate to stage. What's working, what's being cut, what's being tested.

### 7. Engineering
Delivery velocity across four quarters. Tech debt ratio and the plan. Infrastructure uptime, incidents, cost trend. Security posture in one line, flagging anything pending.

Keep this short unless something material is wrong. Boards don't need sprint detail.

### 8. Team
Headcount actual versus plan. Hiring: offers out, pipeline, time-to-fill trend. Attrition split regrettable versus not. Engagement score and trend. Key hires and key open roles.

### 9. Risk and security
Status of critical controls. Certifications in progress with deadlines. Any incidents this period — impact, resolution, prevention. Top three risks with mitigation status.

### 10. Strategic outlook
Next quarter's priorities, three to five, ranked. Decisions needed from the board. Asks.

**The asks slide is the most important one in the deck** and the one most often wasted. *"We'd like three warm introductions to CFOs at Series B companies"* is an ask. *"Any help would be appreciated"* is not.

### 11. Appendix
Detailed model, full pipeline, cohort retention, case studies, headcount detail. Only useful if current — a stale appendix costs credibility across the whole pack.

## Narrative framework

Four acts, and it works for good news and bad alike:

1. **Where we said we'd be** — last quarter's targets.
2. **Where we actually are** — honest assessment.
3. **Why the gap exists** — one cause per variance, not a list of excuses.
4. **What we're doing about it** — specific, dated actions.

The board should know the key message by slide three, not slide thirty.

## Delivering bad news

Never bury it. Boards find out. Finding out late is worse than the news.

1. **State it plainly** — "We missed Q3 ARR by $300K, a 12% gap."
2. **Own the cause** — "Longer-than-expected enterprise sales cycles."
3. **Show you understand it** — "We reviewed eight stalled deals; the pattern is X."
4. **Present the fix** — three specific, dated changes.
5. **Update the forecast** — revised target with the bottom-up build shown.

What not to do: don't lead with good news to cushion bad — boards notice the framing and trust you less for it. Don't explain without owning; "market conditions" is context, not a cause. Don't present a fix with no data behind it, or a revised forecast with no assumptions shown.

## Common mistakes

| Mistake | Fix |
|---|---|
| More than 25 slides | Cut. If you can't explain it in the room, the slide is wrong |
| Metrics without targets | Every metric gets a target and a status |
| No narrative | Data without story makes the board interpret for you |
| Burying bad news | Lead with it, own it, fix it |
| Vague asks | Specific, actionable, assigned to a named person |
| Unexplained variance | One sentence of cause on every gap |
| Stale appendix | Update it or cut it |
| Written to be read, not presented | Decks are spoken aloud — test them that way |

## Cadence

- **Quarterly:** full deck, all sections, 20–30 slides, circulated 48 hours ahead.
- **Monthly, early stage:** metrics, financials, pipeline, top risks. 8–12 slides.
- **Fundraising:** opens with market and vision, closes with the ask. Different animal from a board update — don't reuse one as the other.

## Before you hand it over

List every placeholder still unfilled, and name which section owner needs to supply each. A deck that goes to a board with an invented number in it does more damage than a deck that goes late.
